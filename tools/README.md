# tools: Period utilities

Third-party utilities the official Korean site offered next to the game (DirectX runtimes, an unzip tool, a download manager, document viewers). They are not Helbreath files and are other companies' software, so they are listed with hashes and linked to their copies in [Downloads-Archive](https://github.com/Original-Helbreath/Downloads-Archive/tree/master/wayback_2026), not copied here. The tool this project wrote to unpack the 2.02 installer is in [Tools](https://github.com/Original-Helbreath/Tools) `installer/hb_installer_extract.py`.

## Manifest

`MANIFEST.json` has one row per file: path, size, SHA-256, version, region and era (each with a confidence: verified, inferred or unknown, and its basis), and every origin: source, exact URL, the file's own date and what kind of date it is, the day it was downloaded, and the extraction chain. The format is described in the [top README](../README.md#manifests).
